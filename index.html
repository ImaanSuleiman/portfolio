Machine learning · Python

Text Classification with Machine Learning

6 models, 5 topics, one honest test set

A complete classification workflow on the public 20 Newsgroups sample dataset. I kept 5 topics (hockey, medicine, space, computer graphics, politics), giving 4,724 posts, and stripped headers, footers and quoted replies so the models had to learn from the real words.

Text became numbers with TF-IDF word scores. I then trained and compared Logistic Regression, Linear SVM, Naive Bayes, Random Forest, a Voting ensemble and a Stacking ensemble on identical data, with 80% for training and 20% (927 posts) held back for testing. The code is reusable on any CSV with a text column and a label column.

Public sample dataset: the result is a benchmark, not a client result.

Group project · OS

Chrono Rift

Multi-process, multi-threaded 2D game

Three isolated processes (Arbiter, Human, Strategic) talking over shared memory, written in C++ with POSIX APIs. Mutex and semaphore synchronization, a thread per NPC, stamina-based scheduling, signal-based stun and ultimate moves (SIGALRM), deadlock detection and resolution through a global resource table, contiguous memory allocation with swap, and a non-blocking render thread. Containerized with Docker and a Makefile.
